## 变更规则

1. **每次改文档必须有原因**：无业务/设计理由不随意新增字段、页面或规则。
2. **先改正文，后登记**：内容更新同步到正式文档；本表追加一行（含原因）。
3. **同步导航**：若新增了文档或字段、改变了文档职责，同步更新《项目进度与文档导航.md》。
4. **过程文档不改**：评审纪要/复核报告/修复方案为历史快照，结论变更时改正式文档，不回头改历史。
