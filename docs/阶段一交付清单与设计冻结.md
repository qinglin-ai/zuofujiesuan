## 二、冻结基线要点

### 需求与角色
- 双角色：worker（兼职）/ admin（管理员兼财务）
- 管理后台 = 独立 H5 网页；外部作业/质检系统已成型仅对接；微信支付本期建设；考试人工判定；全功能一次性交付

### 核心状态机
- 任务 tasks.status：open → inProgress → closed
- 作业 assignments.status：claimed → submitted → passed/rejected
- 提现 withdrawals.status：pending → paid/rejected
- 用户 users：approvalStatus(pending/approved/rejected) + status(active/blocked)

### 关键机制（技术基线）
- 并发防超领：`_.inc` 条件自增 + assignment 唯一索引 `(_openid, taskId)`
- 结算幂等：commissions.assignmentId 唯一索引 + 先查后写
- 资金一致：事务（流水+余额）+ 原子增减 + 权限规则封闭客户端写
- 数据库补全：certifications.reviewedBy/reviewTime、withdrawals.payRefNo/paidSource
