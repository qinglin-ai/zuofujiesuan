# 左辅云创 · 兼职人员管理小程序 开发任务拆解表

> 依据《系统架构与开发规划.md》七个阶段拆解到任务级，含预估工时（**人日**，1 人日 = 1 人 1 个标准工作日）与负责人建议。
> 工时均为经验预估值，供排期参考；关键任务（资金/并发/安全类）标注 ⚠ 高优先，需预留联调与测试缓冲。

**角色代号**：PM(项目经理) / BE(云开发/后端工程师) / FE(前端工程师) / QA(测试工程师) / SE(安全工程师) / UI(设计)
