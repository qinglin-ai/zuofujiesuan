# 左辅云创 · 兼职人员管理小程序 原型与 UI 设计（T1-5 交付物）

> 阶段一 T1-5「原型与 UI 设计」产出。本文档为**静态设计基线**：两端核心页面清单、页面布局结构、关键交互与状态映射。实现阶段据此搭建可达原型。
> 形态决策（T1-1 已确认）：兼职人员端=小程序；管理后台=独立 H5 网页。

---

## 二、兼职人员端核心页面布局

### 2.1 任务列表页
```
┌──────────────────────────┐
│ 搜索 / 按标注类型筛选       │ ← 查询 tasks（annotType/status）
├──────────────────────────┤
│ [任务卡] 标题  ★难度       │
│  标注类型 · 单价 · 剩余名额/总人数 │
│  [领取]  [详情]           │ ← 领取→云函数校验/并发控制
├──────────────────────────┤
│ [任务卡] ...              │
├──────────────────────────┤
│ tab: 首页 我的作业  我的  │
└──────────────────────────┘
```

### 2.2 任务详情页（含领取）
```
┌──────────────────────────┐
│ 标题    难度·标注类型      │
│ 任务描述 description       │
│ 单价 ￥xx/件  剩余名额 n/total │
│ 单人任务量 quantity · 截止 deadline │
│ 领取条件：需等级 requireLevel      │
│ 样例图 sampleUrl                  │
│ 禁用项 forbiddenItems              │
├──────────────────────────┤
│ [领取任务]     ← 校验考试/等级/审批/账号 │
└──────────────────────────┘
```

### 2.3 我的作业页（状态分 tab）
```
┌──────────────────────────┐
│ tab: 全部 已领取 已提交 已通过 未通过 │
├──────────────────────────┤
│ [作业卡] 标题             │
│  状态徽标(claimed/submitted/passed/rejected) │
│  提交时间 submitTime       │
│  · 已通过→显示佣金入账金额  │
│  · 已提交→提示去外部系统完成 │
└──────────────────────────┘
```

### 2.4 提现申请页
```
┌──────────────────────────┐
│ 可提现余额 ￥xx             │
│ [金额输入]                 │
│ 收款账户（已绑定卡展示）     │
│  未绑定→[去绑定银行卡]      │
├──────────────────────────┤
│ [确认提现]  ← 校验余额足够 && 已绑卡 │
└──────────────────────────┘
```

## 三、管理后台核心页面布局

### 3.1 注册审批页


```
┌──────────────────────────────────┐
│ 筛选: pending / paid / rejected   │
├──────────────────────────────────┤
│ [#] 姓名 金额 收款账户 申请时间      │
│  [确认到账]  ← 置paid + paidSource=manual │
└──────────────────────────────────┘
```

### 3.4 台账对账导出页
```
┌──────────────────────────────────┐
│ 日期范围: [起]~[止]  按日粒度        │
│ [导出佣金台账] [导出提现流水]        │
├──────────────────────────────────┤
│ 汇总: 累计佣金 累计已提 可用余额      │
└──────────────────────────────────┘
```

## 四、状态-界面映射（一致性约束）

| 状态 | 兼职端呈现 | 管理端可操作 |
|------|-----------|-------------|
| tasks.status=open | 可领取（详情页显示「领取」） | 可关闭 |
| tasks.status=closed | 置灰、不可领 | - |
| assignments=claimed | 待作业（去外部系统） | - |
| assignments=submitted | 待核验文案 | 核验回写（通过/未过） |
| assignments=passed | 显示佣金 + 审核人/时间 | - |
| assignments=rejected | 未通过，不显示佣金 | - |
| withdrawals=pending | 提现中 | 确认到账（半自动） |
| withdrawals=paid | 已到账（到账时间） | - |
| withdrawals=rejected | 被拒（原因：余额不足） | - |
| approvalStatus=pending | 提示等待审批 | 通过/驳回 |
| status=blocked | 禁止操作 | 封禁/解封 |

## 五、设计与实现说明

1. 本文档为**线框级原型**，实现阶段由 UI 产出高保真并落码。
2. 交互与状态机严格对应《业务流程图解.md》与《数据库结构说明.md》，避免页面状态与业务状态错位。
3. 资金相关按钮（领取、提现）一律经云函数校验，前端仅做展示与触发，不做业务判断主控。
4. 管理后台为 H5，采用表格密集布局；兼职端为小程序，采用卡片/tab 布局。
