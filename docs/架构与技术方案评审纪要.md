## 三、评审提出问题与处置

| # | 问题 | 严重度 | 处置 |
|---|------|:----:|------|
| Q1 | 事务单次可写文档数有限，领取高频下事务成本偏高 | 中 | 领取改用原子条件自增降本；事务保留于资金/提现等低频关键点 |
| Q2 | 外部系统判定的"打分/复检"不在本系统，质量追溯仅到"通过/未通过" | 低 | 接受；以 externalRefNo 回查外部系统补足细节 |
| Q3 | admin 身份识别依赖 users.role，需保证云函数内强校验 + 权限规则双写 | 高 | 敏感写全走云函数，云函数内校验 openid→role |
| Q4 | 台账对账导出格式字段口径未定（O1） | 中 | 阶段四 T4-5 前收敛，先预留导出接口 |
| Q5 | 违规处罚对在途作业/余额的处理策略未定（O2） | 中 | 阶段四前确认，定义封禁后作业归属与余额可提性 |
| Q6 | 微信支付打款方式（企业付款到零钱/商户付款）未定（O3） | 高 | T4-6 开工前确认，影响回写实现 |
